# STUDY EXPERIMENT ON MACHINE LEARNING

## Aim
To study the basic concepts, types, workflow, and applications of Machine Learning.

## Objectives
1. To understand the meaning and importance of Machine Learning.
2. To identify the different types of Machine Learning.
3. To study the general workflow used to build a Machine Learning model.
4. To understand the applications and limitations of Machine Learning.

## Theory
Machine Learning (ML) is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

Machine Learning uses data, algorithms, and mathematical techniques to identify patterns and improve performance on a particular task.

## Types of Machine Learning

### 1. Supervised Learning
Supervised learning uses labelled data to train a model. Each training example contains input data and its expected output.

Examples:
- Email spam detection
- House price prediction
- Student result prediction

### 2. Unsupervised Learning
Unsupervised learning uses unlabelled data to discover hidden patterns, relationships, or groups.

Examples:
- Customer segmentation
- Grouping similar documents
- Market analysis

### 3. Reinforcement Learning
Reinforcement learning allows an agent to learn by interacting with an environment and receiving rewards or penalties for its actions.

Examples:
- Robotics
- Game-playing systems
- Autonomous navigation

## General Workflow of Machine Learning
1. Define the problem.
2. Collect relevant data.
3. Clean and preprocess the data.
4. Divide the data into training and testing datasets.
5. Select an appropriate algorithm.
6. Train the model using training data.
7. Evaluate the model using test data.
8. Improve the model if necessary.

## Common Machine Learning Algorithms
- Linear Regression: predicts continuous numerical values.
- Logistic Regression: commonly used for classification.
- Decision Tree: makes decisions using feature-based rules.
- K-Nearest Neighbours (KNN): predicts using similar nearby examples.
- K-Means Clustering: groups similar data points.
- Neural Networks: learn complex patterns from data.

## Applications
1. Healthcare: assisting in medical image analysis.
2. Education: analysing student performance.
3. Banking: detecting suspicious transactions.
4. Retail: predicting customer demand.
5. Transportation: traffic prediction.
6. Email services: detecting spam messages.
7. Agriculture: crop monitoring and yield prediction.

## Advantages
- Identifies patterns in large datasets.
- Automates repetitive prediction tasks.
- Supports data-driven decisions.
- Can improve when suitable new data is available.

## Limitations
- Requires good-quality data.
- Biased training data can produce biased results.
- Some models are difficult to interpret.
- Training and maintaining models can require significant resources.
- Privacy and security must be considered.

## Result
The study of Machine Learning was completed. The different types, workflow, algorithms, applications, advantages, and limitations of Machine Learning were understood.
